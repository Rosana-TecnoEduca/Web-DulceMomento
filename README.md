# Dulce Momento

Sitio estático para el emprendimiento de repostería artesanal Dulce Momento, en Luján, Buenos Aires. Está desarrollado con HTML, CSS y JavaScript, sin proceso de compilación ni dependencias locales.

## Contenido

- `index.html`: estructura, catálogo y formularios.
- `css/style.css`: estilos y diseño adaptable.
- `js/main.js`: menú, modales y mensajes de WhatsApp.
- `images/`: imágenes optimizadas usadas por el sitio. Las imágenes fueron generadas con Meta AI.

## Vista previa

Abrí `index.html` en un navegador o publicá el contenido del repositorio con GitHub Pages.

## Configuración

Los teléfonos de contacto y los nombres del negocio se configuran en el objeto `CONFIG` de [`js/main.js`](js/main.js). Verificá que las personas dueñas de esos números autoricen su publicación antes de hacer público el sitio.
